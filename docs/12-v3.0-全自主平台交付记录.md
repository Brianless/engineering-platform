## 三、启动与接入方式

1. **启动单体零依赖多驱动网关**（无需 Python）：
   ```powershell
   # 默认 auto：自动优先满血插件 → 通用 COM（任意版 AutoCAD/中望/浩辰）→ 离线 ACadSharp
   & "$env:LOCALAPPDATA\EngineeringPlatform\bin\ep-mcp.exe" --port 18080

   # 可选显式指定后端（或通过环境变量 EP_BACKEND）
   & "$env:LOCALAPPDATA\EngineeringPlatform\bin\ep-mcp.exe" --port 18080 --backend com
   & "$env:LOCALAPPDATA\EngineeringPlatform\bin\ep-mcp.exe" --port 18080 --backend offline
   ```
   - Endpoint：`http://127.0.0.1:18080/mcp`（也支持 `--stdio`）
   - Bearer Token：自动生成于 `%LOCALAPPDATA%\EngineeringPlatform\mcp-token.txt`（或通过 `EP_MCP_TOKEN` 指定）
   - 单次调用也可在参数中传 `"dwgPath": "D:\\...\\demo.dwg"` 直走离线 `ACadSharp` 快速通道，或传 `"_backend": "com" | "plugin" | "offline"` 临时指定驱动。
2. **多版本 CAD 一键配置安装程序（推荐 · 图形化 + CLI 双模）**：
   - 双击 `installer/dist/EngineeringPlatform-Setup.exe`（单文件自包含、已代码签名 `Valid`，内置 `net48`/`net8` 宿主、`ep-mcp.exe`、签名证书），自动扫描本机全部 **AutoCAD 2010–2026 / Civil 3D / 中望 ZWCAD / 浩辰 GstarCAD**，支持自由勾选「单个 CAD / 多个 CAD / 全部 CAD」一键配置、自动写入 `TRUSTEDPATHS` 与证书信任、生成 `mcp-client-config.json` 并一键启动网关。
   - 命令行静默部署示例：
     ```powershell
     .\installer\dist\EngineeringPlatform-Setup.exe --list
     .\installer\dist\EngineeringPlatform-Setup.exe --select "Civil 3D 2025"
     .\installer\dist\EngineeringPlatform-Setup.exe --select "Civil 3D 2025,AutoCAD 2022,AutoCAD 2014"
     .\installer\dist\EngineeringPlatform-Setup.exe --all
     .\installer\dist\EngineeringPlatform-Setup.exe --uninstall
     ```
   - 传统 MSI 安装包同样可用：`installer/dist/EngineeringPlatform-v3.0.msi`（或 `.\tools\install_bundle.ps1 -SkipBuild`）
3. **无头真机冒烟自检与回归套件**：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\installer\smoke_headless.ps1
   python tests/run_all.py
   python tests/test_v3_e2e.py
   python tests/test_v31_multidriver.py
   ```
